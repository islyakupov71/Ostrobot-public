# Развёртывание

Используйте собственные отдельные ресурсы для демонстрации.

1. Скопируйте `.env.example` в игнорируемый `.env` и настройте новый Telegram-бот,
   PostgreSQL и случайные секреты. Не используйте рабочую базу команды.
2. Укажите `DOMAIN=app.example.com`, `WEB_APP_URL=https://app.example.com`.
3. Выполните `pnpm install --frozen-lockfile`, `pnpm typecheck` и `pnpm build:all`.
4. Настройте Docker Compose, примените миграции и создайте администратора
   через `BOOTSTRAP_ADMIN_TELEGRAM_ID` согласно `docs/SETUP.md`.
5. Доступ к Google Sheets настраивайте через собственный сервисный аккаунт;
   его ключ храните только в локальном окружении.

В репозитории нет адресов действующего стенда, данных сотрудников и готовых
учётных данных. Пример `examples/team.example.json` намеренно не содержит
Telegram-юзернеймов. Реальный список храните в игнорируемой папке `.local/`.
Скрипт добавления сотрудников принимает путь к этому JSON первым аргументом.
